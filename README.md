# Logartis-Inspired Portfolio Website Redesign

This document provides an overview of the redesigned portfolio website based on the logartis.info aesthetic.

## Overview of Changes

The portfolio website has been completely redesigned to match the look and feel of logartis.info, featuring:

1. **Minimalist Grayscale Aesthetic**
   - Atmospheric misty background on the homepage
   - Clean, centered typography with large, bold headings
   - Dramatic contrast between light homepage and dark content pages

2. **Interactive Elements**
   - Birds animation that responds to mouse movements
   - Smooth page transitions with fade effects
   - Sound toggle functionality
   - Color-coded navigation with subtle hover effects

3. **Responsive Design**
   - Fully responsive layout for all devices (mobile, tablet, desktop)
   - Dark mode support
   - Reduced motion preferences support
   - Print styles

## File Structure

- **HTML Files**
  - `index-logartis-final-fixed.html` - The main HTML file with all content and structure

- **CSS Files**
  - `logartis-style.css` - Main styling for the logartis design
  - `responsive.css` - Responsive design rules for different screen sizes

- **JavaScript Files**
  - `navigation-fixed.js` - Handles page transitions, birds animation, and interactive elements

- **Images**
  - `images/backgrounds/misty_background.jpeg` - Atmospheric background image
  - Various photography images in the images folder

## Key Features

### 1. Birds Animation
The homepage features a flock of birds that responds to mouse movements. When users move their cursor across the screen, the birds change direction and fly away from the cursor, creating an engaging and dynamic experience.

### 2. Page Transitions
Clicking on navigation items triggers smooth transitions between the homepage and content pages. The homepage fades out, and the selected content page fades in with a dark background, creating a dramatic contrast.

### 3. Sound Integration
The website includes a sound toggle button that allows users to enable or disable ambient sounds and transition effects.

### 4. Responsive Design
The website adapts to different screen sizes with specific layouts for desktop, tablet, and mobile devices. It also supports dark mode and reduced motion preferences.

## How to Use

1. Open `index-logartis-final-fixed.html` in a modern web browser
2. Navigate through the website using the color-coded navigation menu
3. Interact with the birds animation by moving your mouse across the screen
4. Toggle sound effects using the sound button in the top-right corner
5. Test responsiveness by resizing your browser window
